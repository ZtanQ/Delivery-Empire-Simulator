# First day checklist

Tick these before you start your first task. It takes 20 minutes and prevents the
three problems that waste the most time in a shared Unity project.

- [ ] Unity `6000.6.1f1` installed. Exactly this one, not a newer or older version.
- [ ] Android Build Support module installed (with OpenJDK and Android SDK/NDK).
- [ ] `git lfs install` has been run on my machine.
- [ ] Repository cloned and the project opens with no errors.
- [ ] Unity smart merge configured, so scene conflicts resolve instead of exploding:
      run `git config --global merge.unityyamlmerge.driver` with the path to
      `UnityYAMLMerge` inside my Unity install, as described in the Unity docs
      for Smart Merge. Ask the lead if the path is unclear.
- [ ] I opened my own sandbox scene and it loads.
- [ ] I read README sections 2, 3 and 4.
- [ ] I have a mid-range Android phone available to test on, or I said so in the channel.
- [ ] I posted "setup done" in the channel.
