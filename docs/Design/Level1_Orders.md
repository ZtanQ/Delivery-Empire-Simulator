# Level 1 Orders

Basic order rules for the player at warehouse Level 1.

## Items

- Each order contains **1–3 units**.
- An order can ask for different products.

## Categories

- Each order can contain **1–2 categories**.
- All 4 categories are available at Level 1:
  - Snacks
  - Dairy
  - Drinks
  - Bakery

## Frequency

- A new order arrives roughly every **30 seconds**.
- Maximum **3 active orders** at once.

## Timer

- Each order has **90 seconds** to be completed.
- The timer can become shorter at higher warehouse levels.

## Goal

Keep Level 1 orders simple so the player can learn the basic
pick-and-deliver loop without being overwhelmed.
